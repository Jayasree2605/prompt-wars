TeamFlow is a fully client-side team collaboration board built as a single HTML file - no backend, no dependencies, deploy-ready.
Features shipped:
Kanban Board - 3-column task board (To Do / In Progress / Done) with drag-and-drop reordering and click-based move buttons
Task Management - Create, edit, and delete tasks with title, description, assignee, priority (High/Medium/Low), and status
Comments - Per-task comment thread with author selection and timestamps
Dashboard - Live stats(total, to-do, active, done), segmented progress bar, team workload panel with mini bar charts, and full task list sorted by urgency
Persistence - All data saved to localStorage; survives refresh with no backend
Search - Real-time filter across all columns by title, assignee, or description
Accessibility - 80+ ARIA attributes, keyboard shortcuts(Esc, Ctrl+Enter), semantic roles
Responsive - Mobile-friendly layout with adaptive grid breakpoints
Design - Google Fonts(Inter), CSS variables, smooth animations, avatar colors from names
